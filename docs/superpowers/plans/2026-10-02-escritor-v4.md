# Escritor v4 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un escritor de biografías que cuenta como una novela, en primera persona y con el tono del narrador, sin agregar hechos. Spec: `docs/superpowers/specs/2026-10-02-escritor-v4-design.md`.

**Architecture:** misma cadena que la v3 (registro → plan → capítulos → verificador/lector/cotejo → una ronda de arreglo por reemplazos → libro e informe), con guía, receta y vara reescritas de cero en `docs/v4/escritor/` y el código copiado a `fabrica/scripts/escritor-v4/` (la v3 queda intacta como historial y para comparar).

**Tech Stack:** Node 20 ESM (`.mjs`), `node --test`, workflows de Claude Code (agentes en la sesión, USD 0 de API).

## Global Constraints
- Modelo: **Opus** para redactar, escribir y juzgar (agentes sin `model`, heredan la sesión). Sonnet solo para correr comandos. Fable no.
- No pisar: archivos nuevos; v3 queda como está.
- Nada de la vida de un narrador real en git ni dentro de prompts/guía/vara (ejemplos de Nélida, inventada). Salidas de pruebas fuera de git.
- Commits en castellano rioplatense con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; push a `v3-escritor`.
- Tests: `node --test "fabrica/scripts/escritor-v4/"*.test.mjs` desde la raíz del worktree.
- Los prompts nuevos los aprueba Naza antes de la prueba (Task 2).

// C29 (v4): el mismo nombre del registro 3+ veces en 3 oraciones seguidas ("Juan Manuel" ×4 en la v3.2) → arreglo.
export function c29(p, reg) {
  const out = [];
  const nombres = (reg?.personas || []).flatMap((x) => [x.nombre, ...(x.apodos || [])]).filter(Boolean).map(norm).filter((n) => n.length > 2);
  for (const par of parrafos(sinCitas(p.texto))) {
    const os = oraciones(par);
    for (let i = 0; i + 3 <= os.length; i++) {
      const v = ` ${norm(os.slice(i, i + 3).join(' '))} `;
      const rep = nombres.find((n) => v.split(` ${n} `).length - 1 >= 3);
      if (rep) { out.push({ control: 'C29', tipo: 'repetido', frase: os[i + 2], que: `"${rep}" 3 veces en tres oraciones: usá "él/ella", "mi hermano" o reordená` }); break; }
    }
  }
  return out;
}
